설치할 것이 없는 정적 웹사이트입니다. `index.html` 을 브라우저로 열면 바로 보입니다.

| 제품 | `products.html` | 단품 82종, 소비자가 표시 (구매 기능 없음). 분류·브랜드·검색·정렬 |

## 고치는 곳

- **제품·가격·브랜드 소개**: `assets/js/ibr-data.js` 하나만 고치면 메인과 제품 페이지에 함께 반영됩니다. 파일 맨 위에 적는 법이 있습니다.
  - 가격은 소비자가(원, 숫자). 모르면 `null` → "준비 중"으로 표시됩니다.
  - 상세페이지가 생기면 해당 제품에 `url: "주소"` 를 넣으면 카드가 그 페이지로 연결됩니다.
  - 사진은 `assets/img/products/` 에 넣고 `img: "assets/img/products/파일명.webp"` 로 적습니다. 사진이 없으면 브랜드 색 위에 제품 모양 그림이 나옵니다.
- **문구·숫자**: `_src/index.html`, `_src/products.html` 을 고친 뒤 아래 명령으로 다시 만듭니다.
  ```
  python3 ibr-web/_build.py
  ```
  (`index.html`·`products.html` 을 직접 고쳐도 되지만, 다음에 다시 만들면 덮어써집니다.)
- **색·글꼴**: `assets/css/ibr.css` 맨 위 `:root` 블록.
- **세계 지도 점**: `tools/make_world.py` (보통은 손댈 일 없음).

## 인트로

- 처음 들어올 때 한 번(브라우저 탭 기준) 약 8.5초 재생됩니다. 아무 곳이나 누르거나 스크롤하면 바로 건너뜁니다.
- 다시 보고 싶으면 주소 끝에 `#intro` 를 붙여 여세요. 예: `index.html#intro`
- 순서: 흩어진 채널 선(기획·브랜딩·퍼포먼스·콘텐츠·홈쇼핑·이커머스·오프라인·해외 수출)이 한 점으로 모임 → IBR 로고가 선으로 그려짐 → *Imagination becomes reality* → 로고가 첫 화면 자리로 내려앉고 서울에서 세계로 선이 뻗음.
- 움직임 줄이기를 켠 기기에서는 인트로 없이 바로 시작합니다.

## 자료 출처

- 회사 소개, 강점, 브랜드 설명: 회사소개서(2025.02), IR 자료(2026.03)
- 가격: 단품별 가격 시트의 **소비자가** 열. 세트·N입 구성·쇼핑백·불량 재고·비매품은 뺐습니다.
- 같은 제품의 용량(100ml/50ml/20ml)이나 향·컬러는 카드 하나로 묶었습니다. 카드에서 용량을 누르면 가격이 바뀝니다.
- IR 자료의 재무·투자·지분 내용은 넣지 않았습니다.

## 확인이 필요한 항목

1. 에이르보 05 딥 모이스트 마스크 500g — 시트 소비자가 **180,000원** (18,000원 오타 가능성). 카드에 "가격 확인 필요" 표시.
2. 시트마다 소비자가가 다른 제품 — 가격 시트 값을 썼습니다.
   - 보타니스트 헤어오일 모이스트 80ml: 가격 시트 35,000 / 라잇나우 시트 45,000
   - 메리비 로우 마누카 허니콤 200g: 70,000 / 메리비 시트 60,000
   - 메리비 MGO 1300+ 250g: 500,000 / 메리비 시트 450,000
3. 소비자가가 비어 있어 "준비 중"으로 넣은 제품 51종 — 츌립·마이베프, 드노아, 닥터다니엘, 청담뉴트리션, 제로가이드, 김국산, 유한양행(당큐락·율리아나), 마지스, 드리아데, 크베트나, 앳플리, 사할리 스낵, 프레시맥, 오트.
4. 스노제로 코골이 방지 스프레이 — SKU 시트에는 '에치에치'로 되어 있으나 회사소개서 설명(구강 유산균·코골이 스프레이)을 따라 제로가이드 아래에 넣었습니다.
5. 하단 회사명은 IR 자료 기준 "주식회사 아이비알커머스"로 적었습니다.
6. 홈쇼핑 채널명은 현재 이름(CJ온스타일, GS샵, 신세계라이브쇼핑)으로 적었습니다.
