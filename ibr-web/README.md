# IBR 회사 홈페이지 (시안)

설치할 것이 없는 정적 웹사이트입니다. `index.html` 을 브라우저로 열면 바로 보입니다.

| 화면 | 파일 | 내용 |
| --- | --- | --- |
| 메인 | `index.html` | 인트로 → 첫 화면 → 통합 마케팅 → SPMP·대표 사례 → 숫자 → 유통 → 글로벌 → 브랜드 → 대표 제품 → 회사 → 제휴 문의 |
| 제품 | `products.html` | 단품 82종, 소비자가 표시 (구매 기능 없음). 분류·브랜드·검색·정렬, 브랜드 필름 |
| 제품 상세 | `product.html` | 제품 사진·용량별 가격·상세페이지 이미지 (상세가 있는 제품만 연결) |
| IR · 소식 | `ir.html` | 언론 보도·보도자료·공지·IR 자료 목록, 글 보기 |

## 고치는 곳

- **제품·가격·브랜드 소개**: `assets/js/ibr-data.js` 하나만 고치면 메인과 제품 페이지에 함께 반영됩니다. 파일 맨 위에 적는 법이 있습니다.
  - 가격은 소비자가(원, 숫자). 모르면 `null` → "준비 중"으로 표시됩니다.
  - 상세페이지가 생기면 해당 제품에 `url: "주소"` 를 넣으면 카드가 그 페이지로 연결됩니다.
  - 사진은 아래 '제품 사진·상세페이지' 도구로 넣습니다. 사진이 없으면 브랜드 색 위에 제품 모양 그림이 나옵니다.
- **문구·숫자**: `_src/index.html`, `_src/products.html` 을 고친 뒤 아래 명령으로 다시 만듭니다.
  ```
  python3 ibr-web/_build.py
  ```
  (`index.html`·`products.html` 을 직접 고쳐도 되지만, 다음에 다시 만들면 덮어써집니다.)
- **색·글꼴**: `assets/css/ibr.css` 맨 위 `:root` 블록.
- **세계 지도 점**: `tools/make_world.py` (보통은 손댈 일 없음).

## 제품 사진·상세페이지

- 제품 사진은 `assets/img/products/`, 상세페이지는 `assets/img/detail/<제품>/` 에 있고, 목록은 `assets/js/ibr-media.js` 입니다(직접 고치지 말고 아래 도구로 만듭니다).
- `python3 ibr-web/tools/make_media.py <목록.json>`: 원본 사진을 웹용으로 줄이고 `ibr-media.js` 를 새로 씁니다. 사용법은 파일 맨 위에 있습니다.
  - 흰 배경 사진은 배경을 투명하게 지웁니다.
  - 긴 상세페이지는 여러 장으로 나눕니다.
  - 움직이는 GIF는 움직임을 살려 바꿉니다.
- 상세페이지가 있는 제품(현재 36종)은 카드를 누르면 `product.html#p-<제품id>` 상세 화면으로 갑니다.

## IR · 소식 (`ir.html`)

- 글 목록은 `assets/js/ibr-ir-data.js` 한 파일입니다. 파일 맨 위에 적는 법과 예시가 있습니다.
- 언론 보도는 `url`(기사 주소)을 넣으면 목록에서 누를 때 새 창으로 기사가 열립니다.
- 직접 쓰는 글(보도자료·공지)은 `body` 에 본문을 넣으면 사이트 안에서 열립니다(`ir.html#post-아이디`). 빈 줄로 문단을 나누고, `## ` 로 시작하는 줄은 소제목입니다.
- 내려받을 자료는 `assets/ir/` 에 넣고 `file` 에 적습니다.
- 사진이 없으면 `brand` 에 적은 브랜드 이름(없으면 IBR)이 썸네일로 나옵니다.
- 날짜가 최신인 글이 위로 자동 정렬되고, 12개씩 보이며 '더 보기'로 이어집니다.
- 날짜는 화면에 보이지 않게 해 두었습니다(정렬에만 씀). 다시 보이게 하려면 `assets/js/ibr-ir.js` 의 `SHOW_DATE` 를 `true` 로 바꿉니다.
