      CH2순간기억3×3 칸에 켜진 순서대로 누르기. 맞힐 때마다 한 칸씩 길어지고 기회는 2번칸 ↑
      CH3색 구분색이 살짝 다른 한 칸 찾기. 30초, 틀리면 2초 감소단계 ↑
      CH4고주파 청력8kHz→19kHz 소리가 들리는지 답하기. 무음 문제 1개 포함, 건너뛰기 가능kHz ↑
      CH5순간계산한 자리·두 자리 덧셈·뺄셈·곱셈을 숫자 패드로. 30초문제 ↑

      2. 환산 기준 (앵커값)

      • CH1200ms → 15세260ms → 20세310ms → 40세360ms → 58세
      • CH29칸 → 17세7칸 → 28세5칸 → 50세3칸 → 74세
      • CH326단계 → 20세18단계 → 36세10단계 → 60세
      • CH417kHz → 24세15kHz → 40세12kHz → 52세

      앵커 사이는 직선으로 이어요. 종합은 가중 평균이에요. 반응 25%, 기억·색·계산 각 20%, 청력 15%. 청력을 건너뛰면 나머지 4개로, 무음 문제에 "들려요"를 누르면 청력을 절반만 반영해요. 연령별 표본으로 만든 규준이 아니라 재미용 기준이에요.

      4. 측정 조건

      1. 환경조용한 곳, 화면 밝기 중간 이상
      2. 청력이어폰 권장, 볼륨은 중간 이하. 스마트폰 스피커는 높은 소리를 잘 못 내요
      3. 재측정7일 뒤 같은 기기, 같은 시간대. 기록지 그래프로 변화를 봐요
      4. 참고눈으로 보고 누르는 단순 반응은 흔히 0.2~0.3초 안팎으로 알려져 있어요. 폰은 화면·터치 지연이 더해져 조금 길게 나와요

      5. 문의 기록

      Q1 청력 테스트 소리가 안 들려요.

      스마트폰 스피커는 높은 주파수를 잘 못 내는 경우가 많아요. 이어폰을 연결하고 볼륨을 중간 정도로 맞춘 뒤 다시 해보세요. 무음 모드도 확인해주세요. 그래도 안 들리면 청력은 건너뛰고 나머지 4개로 계산해요.

      Q2 결과가 매번 달라요.

      정상이에요. 잠, 피로, 집중도, 기기, 화면 밝기에 따라 쉽게 달라져요. 같은 기기로 비슷한 시간대에 여러 번 재고 기록지의 흐름을 봐주세요.

      Q3 의학적 의미가 있나요?

      없어요. 재미로 보는 측정이고 의학적 진단이나 검사가 아니에요. 치매나 난청 같은 질환을 판단할 수 없어요. 걱정된다면 의료기관에서 상담받아 보세요.

      Q4 신체나이 테스트와 같은 건가요?

      비슷하게 가볍게 즐기는 콘텐츠예요. 다만 체력이 아니라 반응, 기억, 색 구분, 고음 듣기, 암산만 재요.

      Q5 기록은 어디에 저장되나요?

      지금 쓰는 브라우저에만 저장돼요. 서버로 보내지 않아요. 도전장 링크에는 내가 적은 이름과 점수만 담겨요.

      Q6 부모님께 도전장은 어떻게 보내요?

      결과 화면에서 "부모님께 도전장 보내기"를 누르고 받는 사람을 고르면 메신저로 링크를 보낼 수 있어요. 받은 사람이 끝까지 하면 두 사람 결과를 나란히 보여줘요.
