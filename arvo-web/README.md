# 에이르보(Árvo) 자사몰 — 카페24 디자인 적용 가이드

이 폴더에는 arvo-official.com(카페24)에 올릴 반응형 디자인이 들어 있습니다.

| 폴더 | 내용 | 어디에 쓰나 |
| --- | --- | --- |
| `cafe24-skin/` | 카페24 스마트디자인 스킨 파일. 메인, 상품 목록, 상품 상세, 브랜드 이야기 화면과 공통 머리말·꼬리말, CSS, JS, 이미지 | 카페24 디자인 FTP 또는 스마트디자인 편집창에 올립니다 |
| `product-images/` | 배경을 지운 정사각형 상품 PNG 11장 | 관리자 상품 등록의 목록·상세 이미지로 씁니다 |
| `prototype/` | 클릭해 볼 수 있는 시안(가짜 상품 데이터) | 디자인 확인용. 카페24에는 올리지 않습니다 |
| `sync_skin.py` | 시안의 CSS·모션·이미지를 스킨으로 복사 | 디자인을 고친 뒤 실행합니다 |

---

## 1. 카페24에서 '판매'가 되는 구조

스킨은 **겉모습만** 바꿉니다. 상품, 가격, 옵션, 재고, 장바구니, 주문서, 결제(PG), 배송비, 회원, 적립금은 지금처럼 **카페24 관리자 기능이 그대로** 처리합니다.

```
관리자에 상품 등록 ──▶ 스킨의 module="..." 자리에 자동으로 표시
                        (이름, 사진, 가격, 품절, 옵션 버튼)
고객이 [장바구니]/[바로 구매] ──▶ 카페24 장바구니 · 주문서 · 결제창 (기존 그대로)
```

- 스킨 파일 안의 `module="product_listmain_1"` 같은 표시가 카페24에게 "여기에 상품을 넣어라"라고 알려 줍니다.
- 상품 상세의 옵션 선택, 수량, 총 상품금액, 장바구니·바로 구매 버튼은 **카페24 기본 스킨의 구매 마크업을 그대로 두고** 모양만 바꿨습니다. 그래서 결제 흐름은 지금 쓰는 몰과 같습니다.
- 장바구니·주문서·로그인·마이페이지·게시판 화면은 카페24 기본 화면을 그대로 쓰고, 위아래 머리말·꼬리말만 Árvo 디자인으로 바뀝니다.
- 이미 운영 중인 몰이라면 PG 계약, 배송 설정, 사업자 정보는 손댈 필요가 없습니다.

**해야 할 일은 네 가지입니다.**

1. 관리자에서 상품·분류·진열을 이 디자인에 맞게 정리한다 (2장)
2. 디자인 보관함에 새 디자인을 만들고 파일을 올린다 (3장)
3. 미리보기 주소에서 실제 주문까지 검수한다 (3-5)
4. 대표 디자인으로 바꾼다 (3-6)

## 2. 관리자 준비

### 2-1. 상품명에 향 번호를 넣어 주세요 (가장 중요)

디자인이 상품명을 읽어 색, 큰 번호, 영문 이름, 향 노트, 사용법을 자동으로 입힙니다.

| 상품명 예시 | 화면에 입혀지는 것 |
| --- | --- |
| `No.07 플로럴 선샤인 퍼퓸 헤어오일` | 살구빛 그라데이션, 07, FLORAL SUNSHINE, 향 노트, 오일 사용법 |
| `No.10 블룸 오브 샤론 리페어 샴푸` | 로즈 그라데이션, 10, BLOOM OF SHARON, 샴푸 사용법 |
| `No.11 포레스트 포그 퍼퓸 헤어오일` | 청회색 그라데이션, 11, FOREST FOG |
| `스칼프 피톤 포레 너리싱 샴푸` | 번호 없음(돌색 바탕), PHYTON FORÊT, 샴푸 사용법 |

- `No.07` `No.10` `No.11` 중 하나가 들어 있으면 됩니다. 영문·한글 향 이름만 있어도 알아봅니다.
- 화면에는 번호를 따로 크게 보여 주므로, 이름 글자에서는 `No.10`만 빼고 보여 줍니다.
- 향 노트, 사용법, 한 줄 설명 문구는 `cafe24-skin/arvo/js/arvo-skin.js` 맨 위 `SCENTS`, `LINES`, `HOW`에서 고칩니다.

### 2-2. 상품 분류(카테고리)

관리자 > 상품 > 상품 분류 관리에서 대분류를 아래처럼 두면 머리말 메뉴, 모바일 메뉴, 목록 화면 탭, 꼬리말이 자동으로 같아집니다.

1. 전체 상품 (모든 상품을 넣어 둡니다. 첫 번째 분류가 '전체 상품 보기' 링크가 됩니다)
2. 헤어오일
3. 케어
4. 스칼프 · 살롱

목록 화면 위 한 줄 설명은 분류 이름이 위와 같을 때 자동으로 나옵니다 (`arvo-skin.js`의 `CATEGORY_COPY`).

### 2-3. 용량과 옵션

- 헤어오일 3종은 **용량을 옵션으로** 등록하는 것을 권합니다 (예: 20ml / 50ml / 100ml).
- 관리자 > 상품 > 옵션에서 표시 방식을 **버튼형**으로 하면 상세 화면에 네모 버튼으로 나옵니다. 셀렉트형도 같은 디자인으로 정리되어 있습니다.
- 20ml를 따로 파는 상품(미니, 세트)이 있으면 메인의 '처음이라면, 20ml부터' 칸에 올립니다. 없으면 그 칸을 비워 두세요. **진열 상품이 없는 칸은 화면에서 자동으로 숨겨집니다.**

### 2-4. 상품 이미지

- `product-images/`의 배경 없는 PNG를 목록·상세 이미지로 쓰면, 향 색 바탕 위에 병만 떠 있는 시안 모습이 됩니다.
- 상세 화면의 추가 이미지(연출 사진, 라벨 확대, 제형)는 '추가 이미지'로 올리면 썸네일로 나옵니다.
- 이미 쓰는 사진(배경 있는 사진)을 그대로 쓰고 싶으면, 해당 목록의 `class="arvo-list"` 옆에 `data-arvo-thumb="cover"`를 붙이면 사진이 칸을 꽉 채웁니다.
- PNG 투명 배경이 카페24 자동 리사이즈에서 흰 배경으로 바뀌면, 이미지 등록을 '개별 이미지 등록'으로 바꿔 올려 주세요. 미리보기에서 한 번 확인이 필요합니다.

### 2-5. 메인 진열

관리자 > 상품 > 상품 진열 > 메인 진열에서 그룹 번호를 확인하고 아래처럼 넣습니다.

| 메인 화면 칸 | 스킨의 모듈 | 넣을 상품 |
| --- | --- | --- |
| 세 가지 향, 세 가지 기분 (상세의 '세 가지 향 비교', 브랜드 화면에도 같이 나옴) | `product_listmain_1` | No.07 · No.10 · No.11 헤어오일 3개 |
| 처음이라면, 20ml부터 | `product_listmain_2` | 20ml 상품 3개 (없으면 비움) |
| 같은 향으로 감고, 두피까지 | `product_listmain_3` | 샴푸, 마스크, 스칼프, 살롱 제품 |

- 관리자의 그룹 번호가 다르면 `index.html`, `product/detail.html`, `brand/story.html`의 `product_listmain_N`에서 N만 바꾸면 됩니다.
- 히어로와 '향의 무대'의 **"No.07 보기" 버튼은 메인진열 1번에 올린 상품의 상세 주소로 자동 연결**됩니다. 상품 번호를 따로 적을 필요가 없습니다.

### 2-6. 그 밖의 관리자 설정

| 항목 | 위치 | 화면 |
| --- | --- | --- |
| 상품 요약설명 | 상품 등록 > 요약설명 | 상품 칸의 한 줄 설명, 상세 제목 아래 설명. 비우면 향 설명이 자동으로 들어갑니다 |
| 관련상품 | 상품 등록 > 관련상품 | 상세의 '함께 쓰면 좋은 제품' |
| 상품 정보 표시 설정 | 쇼핑몰 설정 > 상품 설정 > 상품 보기 설정 | 상세의 가격표 줄(판매가, 배송비, 적립금). **첫 줄은 상품명으로 두세요.** 기본 스킨처럼 첫 줄은 숨겨집니다 |
| 상품정보제공고시 | 상품 등록 > 상품정보제공고시 | 법정 표시 항목. 미리보기에서 상세에 보이는지 확인하고, 안 보이면 상세설명 아래에 넣어 주세요 |
| 내 쇼핑몰 정보 | 쇼핑몰 설정 > 기본 설정 | 꼬리말의 상호, 대표자, 사업자등록번호, 통신판매업 신고번호, 주소, 개인정보보호책임자 (자동 표시) |
| 고객센터 정보 | 쇼핑몰 설정 > 고객센터 | 꼬리말의 전화, 운영시간, 이메일 |
| 게시판 | 게시판 관리 | 꼬리말의 공지사항, 상품 후기, 상품 문의 링크 (자동) |

## 3. 올리기 (운영 중인 화면은 마지막까지 그대로)

### 3-1. 새 디자인 만들기

1. 관리자 > 디자인(PC/모바일) > 디자인 보관함
2. **디자인 추가**로 카페24 무료 **기본 반응형 디자인**을 하나 추가합니다. 이 스킨 파일은 그 디자인을 바탕으로 만들었습니다.
3. 새 디자인의 스킨 번호(예: `skin7`)를 적어 둡니다.
4. 반응형 하나로 PC와 모바일을 같이 쓰므로, 모바일 디자인 설정에서 **모바일 전용 디자인 사용 안 함**으로 둡니다.

### 3-2. 파일 올리기

**방법 A — 디자인 FTP (권장)**

1. 관리자 > 디자인 > 디자인 FTP에서 접속 권한을 신청하고 비밀번호를 받습니다.
2. FileZilla 같은 프로그램으로 접속해 새 디자인 폴더(예: `/skin7/`)로 들어갑니다.
3. `cafe24-skin/` **안의 내용물**을 폴더 구조 그대로 덮어씁니다.

| 파일 | 새 파일 / 바꾸는 파일 | 역할 |
| --- | --- | --- |
| `index.html` | 바꿈 | 메인 (스크롤 모션) |
| `product/list.html` | 바꿈 | 상품 목록 |
| `product/detail.html` | 바꿈 | 상품 상세 (구매 마크업은 기본 스킨 그대로) |
| `layout/basic/layout.html` | 바꿈 | 장바구니·주문·회원 화면의 머리말·꼬리말 |
| `brand/story.html` | 새 파일 | 브랜드 이야기 (`/brand/story.html`) |
| `arvo/` 폴더 전체 | 새 폴더 | Árvo 전용 레이아웃, 머리말·꼬리말, CSS, JS, 이미지 |

**방법 B — 스마트디자인 편집창**

1. 새 디자인의 '편집'을 눌러 스마트디자인 편집창을 엽니다.
2. 위 표의 HTML 파일을 하나씩 열어 내용을 통째로 붙여 넣고 저장합니다. 없는 파일과 폴더(`arvo/`, `brand/`)는 폴더 추가·화면 추가로 만듭니다.
3. `arvo/img/`의 이미지 29장은 같은 폴더에 업로드합니다.

### 3-3. 메뉴 연결

- 머리말 '브랜드' 메뉴는 `/brand/story.html`로 이미 연결되어 있습니다.
- 공지 띠 문구는 `arvo/inc/header.html` 맨 위에서 고칩니다.

### 3-4. 미리보기

`https://{몰아이디}.cafe24.com/skin-skin7/` 처럼 스킨 번호를 넣은 주소로 접속하면, 운영 중인 화면은 그대로 둔 채 새 디자인을 볼 수 있습니다. PC와 휴대폰 양쪽에서 확인하세요.

### 3-5. 검수 목록

- [ ] 메인: 첫 방문 시 로고에 오일 방울이 떨어지는 오프닝(1.5초)이 한 번 나오고, 새로고침하면 다시 나오지 않는다
- [ ] 메인: 히어로가 7초마다 07 → 10 → 11로 바뀌고, "No.10 보기"가 실제 상품 상세로 간다
- [ ] 메인: 스크롤하면 문장이 단어 단위로 밝아지고, '향의 무대'에서 색·병·숫자가 07 → 10 → 11로 바뀐다
- [ ] 메인: 세 진열 칸에 상품, 가격, 할인가가 맞게 나온다. 빈 칸은 숨겨진다
- [ ] 메뉴: 대분류가 머리말·모바일 메뉴·꼬리말에 나오고, 지금 보는 분류에 밑줄이 그어진다
- [ ] 목록: 정렬, 페이지 번호, 향 칩(07·10·11) 거르기가 된다
- [ ] 상세: 옵션 버튼을 누르면 아래에 고른 옵션 줄과 총 상품금액이 나온다
- [ ] 상세: 수량 −/+, 장바구니, 바로 구매, 관심상품이 된다. 품절 상품은 '품절'로 바뀐다
- [ ] 상세: 휴대폰에서 아래로 내리면 하단 구매 바가 나온다
- [ ] 상세: 향 노트, 향 이야기, 사용법, 관련상품, 리뷰, 상품 문의, 결제·배송·교환 안내가 나온다
- [ ] 장바구니 → 주문서 → 결제창(테스트 결제 또는 무통장)까지 끝까지 진행된다
- [ ] 로그인, 회원가입, 마이페이지, 주문 조회 화면이 깨지지 않는다
- [ ] 꼬리말에 사업자 정보가 모두 나온다
- [ ] 검색: 머리말 '검색'을 누르면 검색창이 열리고, Enter로 검색된다

### 3-6. 적용

검수가 끝나면 디자인 보관함에서 새 디자인을 **대표 디자인으로 설정**합니다. 문제가 생기면 이전 디자인을 다시 대표 디자인으로 바꾸면 바로 돌아갑니다.

## 5. 고칠 때

| 바꾸고 싶은 것 | 고칠 곳 |
| --- | --- |
| 공지 띠 문구 | `arvo/inc/header.html` |
| 히어로 사진·문구, 향의 무대 문구 | `index.html` (사진은 `arvo/img/hero-07-wide.webp` 등) |
| 향 노트, 사용법, 상품 칸 한 줄 설명 | `arvo/js/arvo-skin.js` 위쪽 `SCENTS`, `LINES`, `HOW` |

| 브랜드 이야기 문구 | `brand/story.html` |
| 움직임 | `arvo/js/arvo-motion.js`. 휴대폰의 '동작 줄이기' 설정을 켠 고객에게는 움직임 없이 내용만 보입니다 |

디자인 자체(색, 글꼴, 여백)를 바꿀 때는 시안을 먼저 고친 뒤 스킨으로 옮깁니다.

```bash
python3 arvo-web/prototype/_build.py   # 시안 다시 만들기 (prototype/_src → prototype/*.html)
python3 arvo-web/sync_skin.py          # 시안의 CSS·모션·이미지를 cafe24-skin/arvo/ 로 복사
```

## 6. 확인이 필요한 것

- **가격**: 시안의 가격(12,000원 / 29,000원 / 46,000원 등)은 예시입니다. 스킨에는 관리자에 입력한 가격이 그대로 나옵니다.
- **용량 표기**: 받은 시트에는 No.07·No.11이 20ml/50ml로 되어 있고, 제품 컷 파일 이름은 '100'으로 되어 있습니다. 실제 판매 용량을 확인해 옵션을 맞춰 주세요.
- **모델 사진**: 대화창에 올려 주신 모델 사진은 파일로 받지 못해 이번 디자인에 넣지 못했습니다. zip으로 다시 주시면 브랜드 이야기와 인스타그램 칸에 넣겠습니다.
- **포레스트 포그 그루밍 토닉**: 제품 이미지가 없어 시안에 넣지 않았습니다.
- **실제 카페24 화면에서 처음 확인할 것**: 이 스킨은 카페24 기본 반응형 디자인의 모듈 마크업을 그대로 옮겨 만들었고, 카페24가 그려 주는 모습을 흉내 낸 화면으로 모양을 점검했습니다. 실제 카페24 서버에서는 아직 돌려 보지 않았으므로, 옵션 버튼 모양, 하단 구매 바, 쿠폰·추가구성상품처럼 카페24가 그때그때 그리는 부분은 미리보기에서 꼭 확인해 주세요. 어긋나는 곳은 `arvo/css/arvo-cafe24.css`에서 맞춥니다.
- **글꼴**: 한글 Pretendard(jsDelivr), 영문 Montserrat와 숫자 Playfair Display(Google Fonts)를 불러옵니다.
