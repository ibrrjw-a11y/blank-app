01하는 법

  1. 화면에 그림 한 장이 6.7배 확대돼서 나와요.
  2. 뭔지 한글로 적고 맞히기.
  3. 틀리면 한 칸 줌아웃: 6.7 → 4.5 → 3.2 → 2.3 → 1.7 → 1.3배.
  4. 2번 틀리면 분류 힌트, 3번 틀리면 보기 4개 버튼이 열려요.

Q&A

문제는 언제 바뀌나요?

매일 0시(한국 시간)에 바뀌어요. 같은 날엔 누구나 같은 그림을 풀어요.

보기 힌트를 쓰면 손해인가요?

점수는 똑같이 "몇 번 만에 맞혔나"로 남아요. 결과 화면에 보기 힌트를 썼다는 표시만 붙어요.

그림은 어디서 오나요?

기기에 깔린 이모지 글꼴을 크게 그려서 써요. 그래서 아이폰과 갤럭시에서 그림 모양이 조금 달라요.

기록은 어디에 남나요?

이 브라우저에만 남아요. 플레이 수, 성공률, 연속 성공, 시도 분포를 나만 봐요.
